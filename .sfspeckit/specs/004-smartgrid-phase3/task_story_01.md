## Requirements

Build the Universal AI Adapter architecture that translates natural language prompts into structured SOQL query specifications:

1. **`ISmartGridAIProvider` (Apex Interface)**:
   - Contract for all AI adapters:
     - `SmartGridNLPEngine.TranslationResult translateQuery(SmartGridNLPEngine.TranslationRequest req)`
     - `SmartGridNLPEngine.AssistantResult answerQuestion(SmartGridNLPEngine.AssistantRequest req)`
2. **`SmartGridMockAIProvider` (Apex Adapter)**:
   - Rules-based / regex heuristic parser that translates standard phrases (`"rating is hot"`, `"sort by name desc"`, `"closed won opportunities"`) without network callouts.
   - Provides 0 ms latency, 0 token cost, and acts as the reliable test / offline runner.
3. **`SmartGridExternalAIProvider` (Apex Adapter - BYO-LLM)**:
   - Callout adapter connecting via Named Credentials to external LLM endpoints (OpenAI, Anthropic Claude, Google Gemini, Azure OpenAI, vLLM).
   - Posts user prompt + schema context, receives JSON response, and maps it to normalized DTO.
4. **`SmartGridEinsteinAIProvider` (Apex Adapter - Native Einstein)**:
   - Integrates with Salesforce `ConnectApi.EinsteinLlm` / `PromptTemplate` for native Einstein 1 customers.
5. **`SmartGridNLPEngine` (Apex Orchestrator & Controller)**:
   - Factory method that instantiates the provider based on `Smart_Grid_AI_Config__mdt`.
   - Exposes `@AuraEnabled(cacheable=false) public static TranslationResponse processPrompt(String prompt, String objectApiName, String configDevName)`.
   - Validates JSON output through `GridQueryBuilder.buildQuery()` before returning query parameters to the UI.

## Acceptance Criteria

- **AC-P3-01-1**: Calling `processPrompt` with `"Show accounts in California with rating Hot"` returns a valid `TranslationResult` containing `fields`, `filters`, and sanitized SOQL string generated by `GridQueryBuilder`.
- **AC-P3-01-2**: Any untrusted or malformed field generated by an LLM is rejected by `GridQueryBuilder` with a clear user-friendly exception.
- **AC-P3-01-3**: Provider switching via `Smart_Grid_AI_Config__mdt.Provider_Type__c` dynamically routes requests to the correct adapter without code changes.
- **AC-P3-01-4**: In offline or mock mode, heuristic translation resolves filters with 100% determinism.
